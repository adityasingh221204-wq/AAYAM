NODE INSPECTOR

Node: Malicious APK RAT

📱
HIGH SEVERITY Layer: Technical Delivery

Attackers distribute Trojanized APKs disguised as official electricity bill updates or PM-Kisan verification tools. Once installed, the APK requests accessibility permissions, intercepts 2FA SMS OTPs, and relays them to remote servers.

COMMON TRIGGER SIGNATURES:
  • Direct link to .apk file via WhatsApp or SMS
  • Prompts user to enable "Install from Unknown Sources"
  • Requests accessibility service and SMS read permissions
🛡️ Tactical Interception: Screen the APK or text with CyberDrishti. Turn on Airplane mode immediately if already installed.
